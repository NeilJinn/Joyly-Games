# Joyly Motion System · M2 Playground

Standalone visual playground for stacking Motion Core primitives.

## What lives here

- Primitive browsing for the Motion Core blocks
- Stack editing and parameter tweaks
- Motion pack save/load using `localStorage`
- PNG import for trying different source art
- Scene switching for comparing the same motion pack under different looks

## How to open

Visit `/jms/` while the local server is running.

## Notes

- This page depends on the M1 runtime helpers.
- Reduced-motion settings are respected by the shared runtime.
- `window.JMSMotion` is still exposed for quick inspection and bridge work.
