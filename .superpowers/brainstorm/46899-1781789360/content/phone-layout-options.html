手机端布局方向

当前 UI 内容集中在屏幕中间小卡片里，很多垂直空间没用到。以下是三种改进方向。

当前：居中小卡片
上下空间浪费

A · 现状（对比参考）

内容用 place-items:center 居中，答题按钮 min-h 64px，手机上显得小且紧凑。

填满屏幕
按钮更大

B · 全屏填充（推荐）

内容从上到下铺满屏幕，答题按钮自动 flex 撑高，信息层级清晰。去掉 place-items:center，改为从顶部对齐流式布局。

卡片撑满
保留卡片感

C · 拉伸卡片

保留单张卡片视觉风格，但让卡片 min-height: calc(100vh - topbar)，内部 flex 撑满。卡片感更强但顶部空间利用有限。
